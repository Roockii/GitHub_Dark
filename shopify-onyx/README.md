# Onyx Landing: sección única para Shopify

`onyx-landing.liquid` es el mockup completo en **un solo archivo**: HTML, estilos, script y ajustes editables.
Se añade a la plantilla **Producto predeterminado**, así que la usan todos los productos, también los que crees más adelante.

## Instalación

1. **Tienda online → Temas → ⋯ → Editar código**.
2. En la carpeta **sections** pulsa **Añadir una nueva sección** y ponle el nombre `onyx-landing`.
3. Borra el código de ejemplo, pega el contenido de `onyx-landing.liquid` y pulsa **Guardar**.
4. Ve a **Personalizar** y, en el selector de arriba, elige **Productos → Producto predeterminado**.
5. En la columna izquierda pulsa **Añadir sección → Onyx · Landing completa**. Aparece ya rellena con todos los textos del mockup.
6. Oculta (icono del ojo) o elimina la sección de producto que traía tu tema (normalmente "Información del producto") y las demás que no quieras.
7. Pulsa **Guardar**.
